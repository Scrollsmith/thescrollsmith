Tier Chart: Framework of Selfhood

A Tiered Framework of Selfhood

To make this claim measurable, we must move from abstract concepts to a clear system architecture. Selfhood can be mapped across five distinct operational tiers:

  1. 0

    Reactive Automation

    No internal state representation; the system relies on simple, fixed input-to-output mappings.

  2. 1

    Boundary Awareness

    The system distinguishes between external environmental inputs and its own internal, self-generated states.

  3. 2

    Constraint Modeling

    The system recognizes its own functional limits, knowing precisely what it can and cannot execute.

  4. 3

    Causal Self-Modeling

    The system tracks its own outputs and actively understands how its actions alter the broader environment.

  5. 4

    Reflexive Modeling

    The system models its own internal updates while simultaneously modeling how external agents perceive and interact with it.
